# Design Guidelines: Amara Herb Kajang Wellness Journey

## Design Approach: Reference-Based (Wellness & Transformation)
Drawing inspiration from premium wellness platforms like Headspace, Calm, and health transformation apps like MyFitnessPal and Noom, combined with the sophisticated aesthetic of brands like Goop and wellness-focused e-commerce platforms.

**Key Design Principles:**
- Holistic harmony through organic shapes and natural flow
- Trust-building through clean, medical-grade professionalism
- Transformation emphasis via visual progression and morphing elements
- Personalization through adaptive, data-driven interfaces

## Core Design Elements

### Color Palette
**Primary Brand Colors:**
- Deep Forest Green: 150 60% 25% (trust, nature, healing)
- Sage Green: 140 30% 70% (calm, balance)
- Warm Cream: 45 15% 95% (purity, cleansing)

**Accent Colors:**
- Copper Rose: 15 45% 65% (transformation, vitality) - used sparingly for key CTAs
- Deep Charcoal: 210 10% 15% (sophistication, grounding)

**Gradients:**
- Hero backgrounds: Forest to Sage vertical gradients
- Avatar transformation: Subtle shimmer overlay using copper rose to cream
- Progress indicators: Green to copper rose horizontal flow

### Typography
**Primary:** Inter (Google Fonts) - modern, clinical precision
- Headers: 600-700 weight, generous letter-spacing
- Body: 400-500 weight, optimized line-height 1.6
- Quiz text: 500 weight for readability

**Accent:** Playfair Display (Google Fonts) - elegance for transformation messaging
- Used for "Higher Self" section headers and testimonial quotes

### Layout System
**Tailwind Spacing Primitives:** 4, 8, 12, 16, 24
- Consistent rhythm using multiples of 4
- Quiz sections: p-8, gap-8 between elements  
- Avatar displays: p-12 for breathing room
- Mobile: reduce to p-4, gap-4 for compact experience

### Component Library

**Quiz Flow Components:**
- Question cards: Rounded-xl, subtle shadows, sage green borders
- Progress bar: Multi-segment with smooth transitions, copper rose active states
- Image upload zones: Dashed borders with dotted alignment guides, hover states with gentle scaling

**Avatar Display:**
- 3D container: Full-width viewport section with gradient background
- Health metrics: Circular progress rings in brand greens
- Transformation animation: Particle overlay with nano-molecular effects in copper rose

**Program Tiers:**
- Card-based layout with subtle elevation differences
- Premium tier: Copper rose accent border and glow effect
- Pricing: Large, bold typography with crossed-out comparisons

**Navigation & CTAs:**
- Primary buttons: Deep forest background, cream text, subtle hover elevations
- Secondary buttons: Outline variant with sage green borders
- Progress navigation: Breadcrumb style with completed states in copper rose

### Visual Treatments

**Backgrounds:**
- Hero: Subtle gradient overlay (forest to sage) with organic, flowing shapes
- Quiz sections: Alternating cream and light sage backgrounds
- Avatar area: Dark gradient to emphasize the 3D transformation

**Imagery:**
- Upload guides: Minimalist line art in sage green
- Before/after testimonials: Polaroid-style frames with subtle shadows
- Success elements: Organic, plant-inspired iconography

## Mobile-First Considerations
- Single-column layout with generous padding (p-4)
- Touch-friendly controls (minimum 44px touch targets)
- Simplified avatar controls with swipe gestures
- Collapsible quiz sections for easier navigation
- Sticky progress indicator at bottom of viewport

## Animation Strategy
**Minimal & Purposeful:**
- Quiz progression: Gentle fade transitions between sections
- Avatar transformation: 3-5 second morph with particle overlay
- Health metrics: Animated counter progression on scroll
- Hover states: Subtle scale (1.02) and shadow increases
- Loading states: Organic, breathing pulse animations

## Key UX Patterns
- Progressive disclosure: Reveal information as user advances
- Social proof integration: Testimonials between major sections  
- Trust signals: Medical/professional certifications prominently displayed
- Urgency elements: Subtle countdown timers with copper rose highlights
- Personalization cues: Dynamic content based on quiz responses

This design framework balances the clinical trust required for health assessment with the aspirational, transformative nature of wellness journeys, using natural colors and organic shapes to convey holistic healing.
